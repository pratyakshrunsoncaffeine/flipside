# Flipside site

A static page that replays a real `make demo` run, with Flip (the bot from the film), the Switch connection diagram, the real Slack and Mattermost screens, and the 65 second film.
The repo is private, so the site is not hosted.

## View it

Open `site/index.html` in a browser, or serve the folder:

```
cd site && python3 -m http.server 8765 --bind 127.0.0.1
```

Then open http://127.0.0.1:8765/.
Both work offline, except the Inter and JetBrains Mono fonts, which fall back to system fonts.
`http.server` does not answer range requests, which Safari needs for video; in Safari, open the file directly.

## Files

- `index.html`: the page, with its CSS and JS inline.
- `run.js`: generated by `build.py` from an evidence log; do not edit it.
  Rebuild with `python3 site/build.py evidence/demo-mattermost-<case>-<time>.log`.
- `flip.js`: Flip, rendered with the vendored `vendor/three.min.js` (r160, MIT, `vendor/THREE-LICENSE`).
- `media/`: the film (SHA-256 in `VERIFICATION.md`), its poster, and crops of screenshots in `evidence/`.

## Checks

`uv run pytest tests/test_site.py`: links resolve, `run.js` matches its log, three.js is pinned, the film stays under 15 MB.
